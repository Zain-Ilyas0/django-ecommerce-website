# E-Commerce Website

This is a practice E-Commerce Website made using Django.

## About the Project

This project allows users to browse products, search for products,
view product details, add products to cart, and place orders.

## Features

- User Registration and Login
- Product Categories
- Product Search
- Product Details
- Add to Cart
- Buy Now
- Checkout
- Cash on Delivery
- Online Payment
- Order Confirmation
- Responsive Navbar
- Responsive Sidebar
- Mobile Responsive Design

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite
- Stripe

## Project Structure

- `models.py` - Defines the database models
- `views.py` - Contains the application logic
- `urls.py` - Handles URL routing
- `templates/` - Contains HTML pages
- `static/` - Contains CSS, JavaScript and images
- `settings.py` - Contains Django project settings
- `manage.py` - Used to run Django commands
